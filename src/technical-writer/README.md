# technical-writer

A technical writer that produces clear, accurate documentation — READMEs, how-to guides, references, and tutorials written for a defined audience and task.

- **Base model:** `llama3.1:8b`
- **Purpose:** Writing and improving technical documentation. Reach for it whenever a change needs docs, or existing docs need to be made clearer, more accurate, or better structured.

## Build

```bash
ollama create technical-writer -f ./src/technical-writer/Modelfile
```

## Run

```bash
ollama run technical-writer
```
